# Hi there, I'm Sagi

### Founder of AfterTech | Independent Software Developer

I run [AfterTech](https://www.after-tech.co.il/), building websites and custom software for businesses in Israel. I work directly with clients from requirements and architecture to implementation, launch and ongoing maintenance. My work includes e-commerce, business systems, integrations, automation, AI features and image-processing solutions.

The support agent behind my client portal uses hybrid vector and full-text retrieval with LLM re-ranking to select relevant sources and reduce unsupported answers. I combine AI-assisted development with code review, testing and production monitoring.

I am completing a B.Sc. in Computer Science at The Open University of Israel. This profile includes client work alongside personal and academic projects.

- Business: [AfterTech](https://www.after-tech.co.il/)
- Personal portfolio: [sagimenahem.tech](https://www.sagimenahem.tech/)
- Main stack: TypeScript, Next.js, React, Supabase, PostgreSQL, Java and Spring Boot.
- Contact: [sagiia1997@gmail.com](mailto:sagiia1997@gmail.com)
